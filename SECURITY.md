# Security Policy

Report vulnerabilities privately through GitHub security advisories:

https://github.com/agent-passport-system/agent-passport-gateway/security/advisories/new

Please do not open public issues for security reports. Include the affected commit, a reproduction, and the impact you observed. We will acknowledge the report and coordinate a fix and disclosure with you.

Issues in the protocol or SDK itself belong at https://github.com/agent-passport-system/agent-passport-system/security/advisories.
